# Applications of Wavelet Transform in Image Processing

This project was developed as part of my 9th-semester coursework at the **Central University of Odisha** for my 5-Year Integrated M.Sc. in Mathematics. It explores the use of wavelet transforms in image denoising, compression, and feature extraction.

## 🧠 Overview
- Implemented wavelet-based denoising and compression in MATLAB
- Compared performance using PSNR, SSIM, and visual quality
- Analysed different wavelet families (Haar, Daubechies, Symlet, Biorthogonal)

## 🧰 Technologies Used
- MATLAB 
- Basic Image Processing Techniques

## 📊 Results
- Achieved noise reduction with improved edge preservation
- Demonstrated efficient compression with minimal detail loss
- Tested on standard grayscale images
